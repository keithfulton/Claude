Thin-line Lucide icon wrapper — use for arrows, checks, close and capability glyphs; substitute for Cohere's custom icon font.

```jsx
<Icon name="arrow-right" size={16} />
```

Needs `<script src="https://unpkg.com/lucide@0.460.0/dist/umd/lucide.min.js"></script>` loaded before render. Keep strokeWidth at 1.5.
